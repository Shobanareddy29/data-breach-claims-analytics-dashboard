# Data Breach Claims Analytics Dashboard

## Overview
This project analyzes data breach claims data to identify trends in claim approvals, settlement amounts, and processing efficiency.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design

## Dashboard Preview

![Dashboard](dashboard_screenshot.png)

## KPIs
- Total Claims
- Approval Rate
- Total Settlement Amount
- Average Processing Days

## Key Insights
- Analyzed 1,000+ claims records.
- Measured claim approval trends.
- Evaluated settlement amount distribution.
- Monitored average claim processing time.
- Visualized claims across industries and regions.
